# Rent a Car – WordPress Website

A complete WordPress-based car rental website developed for a technical test.  
It features a custom plugin named **Rent a Car** that manages car listings, brands, and details via custom post types and taxonomies.

### Features
- Custom Post Type: Cars  
- Custom Taxonomy: Brand  
- Meta Fields: Price, External Link  
- REST API Integration  
- Swiper.js Slider for Car Display  
- Shortcode: [rent_a_car_slider]  
- Brand-based Filter on Frontend  

### Tech Stack
- WordPress 6.8.3
- PHP 8.x
- JavaScript (ES6)
- Swiper.js
- HTML5, CSS3
- XAMPP (Local Development)
